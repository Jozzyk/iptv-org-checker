# Самопроверяющийся плейлист IPTV-org

1. Создайте отдельный **Public** репозиторий на GitHub с именем `iptv-org-checker`.
2. Загрузите содержимое архива в корень репозитория, включая скрытую папку `.github`. В веб-интерфейсе скрытый файл можно создать через **Add file → Create new file**, введя полное имя `.github/workflows/check-iptv.yml` и вставив его содержимое.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте **Actions → Check IPTV and publish M3U → Run workflow**. Дождитесь успешного завершения обоих заданий.
5. Возьмите адрес из задания **publish** и добавьте к нему `playlist.m3u`. Вставьте полученную ссылку в Televizo. По соседнему адресу `status.json` доступна статистика последней успешной проверки.

Автоматический запуск задан на 01:17 по Нью-Йорку. Ручной запуск доступен в любое время. GitHub может задержать запуск, а в публичном репозитории может приостановить расписание после 60 дней без активности в репозитории.

Проверка берёт публичный список IPTV-org, объединяет варианты по `tvg-id` без суффикса качества вроде `@HD` или `@SD` и сохраняет один вариант на канал. Региональные версии сохраняются отдельно. Для каналов без идентификатора учитываются группа и название. Побеждает вариант, который быстрее отдаёт аудио- или видеопакет во время проверки. Первые пять прошедших проверку каналов убираются из результата. Чтобы оставить их, передайте `--remove-first 0` в workflow. Если новый список пуст, слишком мал или проверка прервётся, GitHub Pages продолжит отдавать последнюю успешно опубликованную версию.

Сервер отдаёт только M3U и статистику. Televizo соединяется напрямую с источниками. Сервер GitHub и ваш Deeper Connect Mini могут видеть разный набор доступных каналов из-за географических ограничений. Проверка оценивает запуск потока в момент проверки. Длительную стабильность воспроизведения она не измеряет.

Для проверки локального образца с установленным FFmpeg используйте `python3 check_playlist.py --input sample.m3u --remove-first 0 --output sample-output`.
